PWA Icons
=========
Place the following icon files in this directory before deploying to production:

  icon-192x192.png  — 192x192 px, PNG, used for Android home screen
  icon-512x512.png  — 512x512 px, PNG, used for splash screen and maskable icon
  apple-touch-icon.png — 180x180 px, PNG, used for iOS home screen

Design guidelines:
- Use a white or transparent background with the MedLink brand mark centred.
- The maskable icon must have the brand mark within the safe zone (80% of the canvas).
- Recommended tool: https://maskable.app/editor for maskable icon preview.

For development, placeholder icons can be generated at:
  https://favicon.io/favicon-generator/
